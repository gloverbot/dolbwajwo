# 돌봐줘 (Flutter 프로토타입)

같은 동네 · 같은 어린이집 부모님끼리 **아이를 잠깐 맡기고 돌봐주는** 앱입니다.

- **돕는 대상**: 아이를 잠깐 맡길 곳이 필요한 부모님
- **푸는 문제**: 갑작스러운 일로 아이를 맡길 곳이 없음
- **핵심 기능**: 급한 부모가 요청 → 동네 부모들에게 알림 → 시간 되는 부모가 수락 → 돌봄 후 캐시 정산

---

## 1. 실행하는 법

### (1) Flutter 설치하기

이 컴퓨터에는 아직 Flutter가 없습니다. 아래 주소에서 Windows용을 받아 설치하세요.
https://docs.flutter.dev/get-started/install/windows

설치가 끝났는지 확인하는 명령입니다.

```bash
flutter doctor
```

### (2) 프로젝트에 안드로이드/웹 폴더 만들기

이 폴더에는 지금 앱 코드(`lib`)만 있습니다. 실행에 필요한 나머지 폴더를 자동으로 만들어 줍니다.
(이미 있는 파일은 지워지지 않습니다.)

```bash
flutter create .
```

### (3) 필요한 것 내려받기

```bash
flutter pub get
```

### (4) 실행하기 — 크롬으로 보는 게 가장 빠릅니다

```bash
flutter run -d chrome
```

휴대폰이나 안드로이드 에뮬레이터로 보려면:

```bash
flutter run
```

## 2. 무엇이 보이면 성공인가요?

1. **가입 화면** — 이름을 적고 동네·어린이집을 고른 뒤 `가입하고 시작하기`
2. **홈 화면** — 위쪽 파란 상자에 `6,000 캐시`가 보입니다 (가입 축하 캐시)
3. `지금 아이 맡기기` → 아이 이름 / 나이 / 시간 / 장소를 적고 알림 보내기
4. **5초 뒤** 이웃 부모(최은주)가 수락하는 알림이 옵니다 → 아래 `알림` 탭에 빨간 숫자
5. 홈의 **우리 동네 도움 요청** 카드를 눌러 `돌봐줄게요` → `돌봄 끝내고 캐시 받기` → 캐시가 올라갑니다
6. `내 정보` 탭에서 캐시가 오간 기록을 확인할 수 있습니다

---

## 3. 캐시 규칙 (바꾸고 싶으면 여기)

`lib/app_state.dart` 맨 위 `CashPolicy` 한 곳만 고치면 앱 전체에 반영됩니다.

| 항목 | 값 |
|---|---|
| 가입 축하 캐시 | 6,000 |
| 1시간 돌봄 | 3,000 캐시 |
| 한 번에 최대 시간 | 2시간 |

---

## 4. 폴더 구조

```
lib/
 ├─ main.dart                 → 앱 시작점
 ├─ app_state.dart            → 데이터와 규칙 (캐시, 요청, 알림)
 ├─ theme.dart                → 색깔·글씨 크기 등 디자인 기본값
 ├─ utils/format.dart         → 숫자·시간을 보기 좋게 바꾸는 도우미
 ├─ widgets/                  → 여러 화면에서 재사용하는 조각
 └─ screens/
     ├─ onboarding_screen.dart    → 가입 화면
     ├─ main_shell.dart           → 아래 탭 3개
     ├─ home_screen.dart          → 홈
     ├─ request_form_screen.dart  → 아이 맡기기 요청 적는 화면
     ├─ request_detail_screen.dart→ 요청 자세히 보기 / 수락 / 완료
     ├─ notifications_screen.dart → 알림함
     └─ my_page_screen.dart       → 내 정보 · 캐시 기록
```

## 5. 지금은 없는 것 (다음 단계)

이 앱은 **프로토타입**이라 서버가 없습니다. 앱을 껐다 켜면 데이터가 사라집니다.

다음에 붙이면 좋은 것:
- 진짜 회원가입 · 로그인
- 데이터 저장 (Supabase 등)
- 진짜 푸시 알림
- 이웃 신원 확인 · 후기 · 신고 기능 (아이 안전에 가장 중요합니다)

> ⚠️ 이 앱은 아이를 잠깐 맡기도록 **도와주는 도구**입니다.
