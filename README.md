# 돌봐줘 (Next.js 웹앱)

같은 동네 · 같은 어린이집 부모님끼리 **아이를 잠깐 맡기고 돌봐주는** 웹 서비스입니다.

- **돕는 대상**: 아이를 잠깐 맡길 곳이 필요한 부모님
- **푸는 문제**: 갑작스러운 일로 아이를 맡길 곳이 없음
- **핵심 기능**: 급한 부모가 요청 → 동네 부모들에게 알림 → 수락하면 채팅방 생성 → 돌봄 후 캐시 정산

---

## 0. Supabase 연결 (이미 되어 있습니다)

데이터가 **인터넷(Supabase)에 저장**됩니다. 그래서 폰이 달라도 같은 요청이 보입니다.

- 연결 정보는 `.env.local` 에 있습니다. (GitHub에 안 올라갑니다)
- 표 만드는 SQL은 `supabase/migrations/` 에 있습니다.
- 로그인은 Supabase Auth를 씁니다. 적으신 **아이디**를 `아이디@example.com` 으로 바꿔서 가입시키므로,
  **비밀번호는 우리 표에 저장되지 않고** Supabase가 암호화해 보관합니다.

> ⚠️ Supabase 대시보드에서 **Authentication → Sign In / Providers → Email → `Confirm email` 이 꺼져 있어야** 합니다.
> 우리 앱은 이메일을 받지 않기 때문입니다.

**둘이서 시연하는 법**: 일반 창과 시크릿 창에서 **서로 다른 아이디**로 가입하고,
**같은 어린이집 이름**을 적으세요. 한쪽에서 요청을 올리면 다른 쪽 홈에 실시간으로 뜹니다.

## 1. 실행하는 법

필요한 것을 내려받습니다. (처음 한 번만)

```bash
npm install
```

개발 서버를 켭니다.

```bash
npm run dev
```

브라우저에서 http://localhost:3000 으로 들어갑니다.

> 💡 휴대폰 화면 크기에 맞춰 만들었습니다. 크롬에서 `F12` → 휴대폰 모양 아이콘을 누르면 실제 앱처럼 보입니다.

## 2. 화면 구성

로그인을 하지 않으면 **어떤 화면도 볼 수 없고** 로그인/회원가입 화면으로 넘어갑니다.

| 화면 | 주소 | 하는 일 |
|---|---|---|
| 로그인 / 회원가입 | `/login` | 가입해야 앱을 쓸 수 있는 관문 |
| 홈 | `/` | 공지사항 · 알림 · 첫 방문 안내 · 동네 요청 목록 |
| 상점 | `/store` | 캐시로 기프티콘 교환, 광고 보고 캐시 받기 |
| 채팅 | `/chat` | 수락으로 만들어진 채팅방 목록 · 대화 |
| AI 매칭 | `/match` | 조건을 고르면 어울리는 이웃을 점수 순으로 추천 |
| 나의 | `/me` | 내 요청 / 계정정보 / 설정 · 데이터 초기화 |

### 회원가입에서 받는 정보

**부모님 정보** — 이름 · 성격 · 잘하는 것 · 아이디 · 비밀번호 · 프로필 사진 · 자기소개 영상 · 동네 · 어린이집

**우리 아이 정보** — 이름 · 나이 · 알아둘 것(알레르기 등). **여러 명 등록**할 수 있습니다.

- 아이를 여기서 등록해 두기 때문에, 나중에 요청을 올릴 때는 **장소와 시간만** 정하면 됩니다.
- 프로필 사진은 200×200으로 줄여서 저장합니다. (그래야 브라우저 저장소에 들어갑니다)
- 자기소개 영상은 파일이 너무 커서 **앱이 켜져 있는 동안만** 재생됩니다. 새로고침하면 파일 이름만 남습니다.

### 요청을 올릴 때 정하는 것

아이 정보는 자동으로 채워지고, 아래 세 가지만 정합니다.

1. **어디서 만날까요?** — 장소
2. **언제부터** — 시작 시각
3. **얼마나 맡길까요?** — 아래 네 가지 중 하나

| 시간 | 캐시 |
|---|---|
| 30분 | 1,500 |
| 1시간 | 3,000 |
| 1시간 30분 | 4,500 |
| 2시간 | 6,000 |

> 아이가 두 명 이상이면 "누구를 맡길까요?"가 함께 나옵니다.

## 3. 이렇게 써보세요 (발표 시연 순서)

1. **회원가입** — 이름·성격·잘하는 것·아이디·비밀번호를 넣고 가입 → 캐시 **6,000** 지급
2. **홈** — 처음 가입한 사람에게만 4단계 **안내문**이 뜹니다
3. **지금 아이 맡기기** — 요청을 올리면 캐시가 빠져나가고, **5초 뒤** 이웃이 수락하며 **채팅방이 자동 생성**
4. **채팅** — 메시지를 보내면 약 2초 뒤 상대가 답장합니다
5. **AI 매칭** — 조건을 **직접 적거나** 골라서 검색 → 로딩 → 이웃을 **일치도 점수 순**으로 추천 → 선택하면 바로 채팅방
   - 우리 동네 이웃 **14명**에서 찾습니다.
   - 목록에 없는 말도 됩니다. `간호사`라고 적으면 소개글에 "간호사로 일했어요"가 있는 이웃을 찾아줍니다.
   - **비슷한 말까지** 찾아줍니다. `공부`로 검색하면 `숙제 도움`·`한글 공부`·`영어`를 하는 이웃이 나옵니다. (`lib/seed.ts`의 `WORD_GROUPS`)
   - 결과 카드에 **어떤 조건이 맞았는지** 초록 딱지로 표시됩니다.
   - 딱 맞는 이웃이 없어도 **"그 밖의 우리 동네 이웃"**을 함께 보여줘서 화면이 비지 않습니다.
6. **채팅방은 돌봄이 끝나면 자동으로 사라집니다.** (요청을 취소해도 정리됩니다)
6. **상점** — 위쪽 캐시 상자를 누르면 5초 광고 후 **+300 캐시**, 아래에서 기프티콘 교환 → 교환 번호 발급
7. **나의** — 올린 요청 / 수행한 요청 / 캐시 기록, 계정정보, 설정
8. **데이터 초기화** — `나의 > 설정 > 데이터 초기화하고 다시 시작` → 회원가입 화면부터 다시

## 4. 캐시 규칙 (바꾸고 싶으면 여기)

`lib/policy.ts` 한 곳만 고치면 앱 전체에 반영됩니다.

| 항목 | 값 |
|---|---|
| 가입 축하 캐시 | 6,000 |
| 돌봄 시간별 캐시 | 30분 1,500 / 1시간 3,000 / 1시간 30분 4,500 / 2시간 6,000 |
| 한 번에 최대 시간 | 2시간 |
| 광고 1편 보상 | 300 캐시 |

## 5. 디자인 규칙

### 색

배경은 하얀색 대신 **따뜻한 크림색(`#FDF8F1`)**, 글씨는 순검정 대신 **부드러운 코코아색(`#4A3A2E`)**을 씁니다. 원색은 쓰지 않고 톤 다운된 색만 씁니다.

**카테고리마다 색을 고정**했습니다. 글자를 안 읽고 색만 봐도 상태를 알 수 있게요.

| 카테고리 | 색 | 쓰이는 곳 |
|---|---|---|
| 도움 기다리는 중 | 브랜드 코럴 | 카드 왼쪽 띠, 상태 딱지 |
| 수락 완료 | 더스티 블루 | 카드 왼쪽 띠, 상태 딱지 |
| 돌봄 끝 | 세이지 그린 | 카드 왼쪽 띠, 상태 딱지, 캐시 적립(+) |
| 취소됨 | 웜 그레이 | 상태 딱지 |
| 캐시 | 허니(앰버) | 캐시 상자·금액은 어디서나 허니 |

**메인 색은 코럴 하나뿐**입니다. `시작하기`, `지금 아이 맡기기`처럼 앱에서 가장 중요한 행동에만 진하게 씁니다.

**버튼 색 = 누른 뒤 바뀌는 상태의 색**으로 맞췄습니다.

- `돌봐줄게요` → 파랑 (상태가 '수락 완료'가 됨)
- `돌봄 끝내고 캐시 받기` → 초록 (상태가 '돌봄 끝'이 됨)

### 모양

- 버튼은 모서리를 완전히 굴린 **알약 모양**, 카드는 크게 굴린 모서리(2rem)
- 그림자는 검정 대신 **따뜻한 갈색**을 아주 옅게 (`shadow-soft`)
- 로고와 첫 화면 그림은 그림 파일 없이 **코드(SVG)로 직접** 그렸습니다 → `components/Logo.tsx`

> 색만으로 구분하면 색약이신 분이 못 알아보므로, 상태 딱지에는 **아이콘과 글자**도 함께 넣었습니다.

색을 바꾸려면 `tailwind.config.ts`, 카테고리 짝지음은 `lib/policy.ts`만 고치면 됩니다.

### 글꼴과 아이콘

- **Pretendard** (둥근 산세리프) — 부드럽고 친근한 인상
- 아이콘은 **구글 Material Symbols (Rounded)**. 선택된 탭은 속이 꽉 찬 모양으로 바뀝니다.
- 기준 글자 크기 **17px** — 본문 18px 이상, 버튼 21px. 야간·저조도에서도 읽기 편하게.
- 명도 대비는 모두 WCAG AA 기준 이상입니다. 순검정 대신 부드러운 먹색(`#2B2F36`)을 씁니다.

새 아이콘은 https://fonts.google.com/icons 에서 이름을 찾아 이렇게 쓰면 됩니다.

```
<Icon name="favorite" filled className="text-2xl text-coral" />
```

## 6. 폴더 구조

```
app/                        → 화면(페이지)들
 ├─ layout.tsx              바깥 틀 + 로그인 관문
 ├─ globals.css             색·버튼 모양 등 공통 디자인
 ├─ page.tsx                홈 (공지사항 · 알림 · 첫 방문 안내)
 ├─ login/page.tsx          로그인 / 회원가입
 ├─ store/page.tsx          상점 (기프티콘 · 광고)
 ├─ chat/page.tsx           채팅방 목록
 ├─ chat/[id]/page.tsx      채팅방
 ├─ match/page.tsx          AI 매칭
 ├─ me/page.tsx             나의 (내 요청 · 계정정보 · 설정)
 ├─ new/page.tsx            아이 맡기기 요청 적는 화면
 └─ request/[id]/page.tsx   요청 자세히 보기 / 수락 / 완료 / 취소

components/                 → 여러 화면에서 재사용하는 조각
 ├─ AppProvider.tsx         데이터 창고 (계정·캐시·요청·채팅·기프티콘)
 ├─ AuthGate.tsx            로그인 안 한 사람 막는 관문
 ├─ BottomNav.tsx           아래쪽 탭 5개
 ├─ Icon.tsx                구글 아이콘
 ├─ RequestCard.tsx         돌봄 요청 카드
 └─ Ui.tsx                  제목·상태딱지·프로필·태그 같은 작은 조각

lib/                        → 도우미 코드
 ├─ types.ts                데이터 모양 설명서
 ├─ policy.ts               캐시 규칙 + 카테고리 색 (여기만 고치면 됨)
 ├─ seed.ts                 이웃·공지사항·기프티콘 목록
 └─ format.ts               숫자·시간 예쁘게 바꾸기

flutter_prototype/          → 먼저 만들었던 Flutter 버전 (참고용, 실행에는 필요 없음)
```

## 7. 인터넷에 올리기 (Vercel 배포)

1. 이 폴더를 GitHub에 올립니다.
2. https://vercel.com 에 GitHub 계정으로 로그인 → `Add New... > Project`
3. 방금 올린 저장소를 고르고 `Deploy`를 누릅니다. (설정은 건드릴 것이 없습니다)
4. 잠시 뒤 `https://...vercel.app` 주소가 나옵니다.

> 지금은 비밀 키(환경변수)를 쓰지 않아서 Vercel에 따로 넣을 값이 없습니다.

## 8. ⚠️ 프로토타입이라 이런 점이 있어요

- **비밀번호가 브라우저에 그대로 저장됩니다.** 서버가 없어서 어쩔 수 없습니다.
  회원가입 화면에도 안내를 넣어두었으니, **실제로 쓰는 비밀번호는 넣지 마세요.**
- 데이터가 **내 브라우저에만** 저장됩니다. 다른 사람 폰에서는 내 요청이 보이지 않습니다.
- 이웃의 수락·채팅 답장·AI 매칭 결과는 **미리 만들어 둔 데이터로 흉내 낸 것**입니다.
- 설정 화면의 스위치는 화면에서만 바뀝니다.

다음에 붙이면 좋은 것:

- Supabase로 데이터 저장 + 진짜 로그인 (비밀번호 암호화)
- 진짜 푸시 알림
- 이웃 신원 확인 · 후기 · 신고 기능 (아이 안전에 가장 중요합니다)

> ⚠️ 이 서비스는 아이를 잠깐 맡기도록 **도와주는 도구**입니다.
> 실제 돌봄은 서로 얼굴을 아는 이웃과 함께하고, 응급 상황에서는 119에 먼저 연락하세요.
